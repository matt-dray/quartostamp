# Changelog

## quartostamp 0.1.1

- Replaced level 3 wih level 2 headers in tabsets (PR
  [\#12](https://github.com/matt-dray/quartostamp/issues/12) closes
  [\#10](https://github.com/matt-dray/quartostamp/issues/10), thank you
  [@Lextuga007](https://github.com/Lextuga007)).

## quartostamp 0.1.0

- Allowed functions to include the text selected by the user (where
  appropriate), rather than just inserting a simple skeleton (closes
  [\#6](https://github.com/matt-dray/quartostamp/issues/6), thank you
  [@Lextuga007](https://github.com/Lextuga007)).
- Added DRY utils functions to replace text and for common callout-box
  code.
- Added messaging for users so they know that the footnote has been
  added to their clipboard.
- Updated function documentation to reflect changes.
- Added {clipr} and {cli}.
- Bump version to v0.1.0.
