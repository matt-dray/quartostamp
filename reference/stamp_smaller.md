# Insert Smaller Font

Insert a class that makes the font smaller in a Revealjs presentation
slide (place on the same line as the slide title).

## Usage

``` r
stamp_smaller()
```

## Value

Nothing. Text is updated in the active document.

## Details

Output looks like this:

    {.smaller}
