# Insert Custom Footer

Insert a custom footer div in a Revealjs presentation slide. Will
include text selected by the user, otherwise skeleton help text will be
inserted.

## Usage

``` r
stamp_footer()
```

## Value

Nothing. Text is updated in the active document.

## Details

The output looks like this if the user hadn't selected any text:

    ::: footer
    Custom footer text
    :::
