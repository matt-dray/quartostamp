# Insert Scrollable Content

Insert a class that allows content to be scrolled if the slide is too
small to hold it (place on the same line as the slide title).

## Usage

``` r
stamp_scrollable()
```

## Value

Nothing. Text is updated in the active document.

## Details

Output looks like this:

    {.scrollable}
