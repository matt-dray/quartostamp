# Package index

## Classes

Classes that impact the content of a Quarto slide if placed on the same
row as the slide title. These are surrounded by curly braces
(i.e. [`{}`](https://rdrr.io/r/base/Paren.html)).

- [`stamp_smaller()`](https://github.com/matt-dray/quartostamp/reference/stamp_smaller.md)
  : Insert Smaller Font
- [`stamp_scrollable()`](https://github.com/matt-dray/quartostamp/reference/stamp_scrollable.md)
  : Insert Scrollable Content
